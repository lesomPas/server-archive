# 第一章 总则

**1.1** 为了标准化服务器管理员的选拔、任用、具体工作内容，保证正常的管理秩序，避免服务器安全事故的发生，建立科学规范的服务器管理员选拔任用制度，形成有效管用、简便易行、有利于优秀人才脱颖而出的选人用人机制，制定本条例。

**1.2** 选拔任用服务器管理员，必须坚持以下原则：
    1. 德才兼备、以德为先；
    2. 人岗相适、人事相宜；
    3. 依规办事。


# 第二章 选拔任用条件

**2.1** 服务器管理员必须具备以下基本条件：
    1. 有意参与服务器管理工作，维护管理秩序；
    2. 有实践经验，有胜任服务器管理员工作的组织能力、沟通水平和专业素养；
    3. 正确行使所赋予的管理权限，依规办事，自觉接受玩家批评，反对任何滥用管理权限的行为；
    4. 具有协作能力，能够与其他服务器管理员一同工作。

**2.2** 提拔担任服务器管理员的，应当具备以下基本资格：
    1. 担任服务器协调管理员的，应当具有一年以上的Minecraft游玩经验和两周以上的创造服游玩经验。
    2. 担任服务器协调管理员以上的，一般应当具有两周以上的本服务器管理经验或曾经长期担任过创造服服主。
    3. 担任服务器中心管理员的，一般应当具有长期独立的创造服管理经验或者有多次应急事件处理经验。
    4. 同时担任服务器命令组管理员的，应当具有3个月以上的Minecraft Bedrock Editor命令使用经验或有自己独立的大型命令作品。

**2.3** 除服务器命令组管理员以外，服务器管理员应当逐级提拔。特别优秀或者工作特殊需要的干部，可以突破任职资格规定或者越级提拔担任职务。
> 因工作特殊需要破格拔的服务器管理员，应当符合以下情形之一：管理团队结构需要或者服务器管理员职位有特殊要求的；专业性较强的岗位或者重要专项工作急需的。


# 第三章 管理组织团队

**3.1** 管理组织团队一般由服务器中心管理员组成，负责服务器内服务器管理员的选拔任用等管理工作。

**3.2** 管理组织团队应当深化对服务器管理员的日常了解，以全方位、多角度近距离了解服务器管理。根据了解日常情况，对管理组织团队选人用人提供依据和参考。

**3.3** 当管理岗位出现空缺时，管理组织团队应当评估：该岗位是否必需、需要何种能力要求、现有玩家中谁符合条件，形成建议后启动选拔程序。

**3.4** 根据工作需要和实际情况，如确有必要，也可以把公开选拔、竞争上岗作为产生人选的一种方式。特别是需要补充紧缺专业人才（例如服务器命令组管理员）或者配备结构需要干部的，可以通过公开选拔产生人选。
公开选拔、竞争上岗应当结合岗位特点，管理组织团队应严格把关，突出管理水平、专业素养。防止简单以分数、票数取人。


# 第四章 免职、降职

**4.1** 服务器管理员有以下行为之一的，一般应当免去现职：
    1. 受到责任追究应当免职的;
    2. 不适宜担任现职应当免职的；
    3. 违反条例应当免职的；
    4. 自愿离职或者调离原岗位的；
    5. 因工作需要或者其他原因应当免去现职的。

**4.2** 实行服务器管理员降职制度。服务器管理员被管理组织团队确定为不称职的，因工作能力较弱、受到组织处理或者其他原因不适宜担任现职务层次的，应当降职使用。

**4.3** 因违反条例应免职的，不得再被提拔为服务器管理员；因受到责任追究应当免职的，除其他条例规定的除外，两周内不得被提拔为服务器管理员。


# 第五章 附则

**5.1** 本条例由服务器管理组织团队解释。

**5.2** 本条例自2026年7月25日起施行。
